# mac-spotify-trey-lyrics 🎵

A simple, lightweight utility for macOS that streams synchronized Spotify lyrics directly into your top Menu Bar (Tray). 

## 🚀 | Installation

### Option A: Using `uv` (Recommended & Fastest)
If you have [uv](https://github.com) installed, just run:

```bash
uv run main.py
```

### Option B: Using standard `pip` & Virtual Environment
If you don't use `uv`, please **activate your virtual environment** first, then run:

```bash
pip install -r requirements.txt
python3 main.py
```

## 🛠 | P.S.
Please ensure you have the official **Spotify Desktop Client** active on your Mac.
